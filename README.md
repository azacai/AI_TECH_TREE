# 大智算科技树（Intelligent Computing Tech Tree）

用《文明》式科技树刻画**大智算产业技术版图**的可交互知识工程：**11 条技术主干、196 个节点、248 条依赖边、5 大终局目标、18 条达成路径**。数据、校验、视图三层解耦，全部可独立维护；一键生成零依赖的单文件交互可视化。

## 这是什么

以"科技树"为隐喻组织大智算（AI Infrastructure）领域的技术版图，视角为**云解决方案架构师**：

- **胜利条件层（终局目标）**：V1 经济性（$/Mtoken）、V2 能力上限、V3 能力广度、V4 轻量普惠、V5 生态自主——每个目标有多条 OR 逻辑的达成路径（beeline），**点亮任意一条路径即可达成，不需要点满整棵树**；
- **主干层（技术锚点域）**：A 芯片 / B 互连网络 / C 模型架构 / D 推理系统 / E 训练与数据 / F 云原生（含容器）/ G 智算中心与能源 / H 通智一体（后发型主干）/ I 存储 / J Agent 使能 / K 科学计算范式（AI4S 负载层）；
- **节点层**：每个节点带显式前置依赖与**指标门槛型点亮判据**（L1 掌握 / L2 商用 / L3 领先 × 量化门槛）——**达不到指标不算点亮**（例：训练可用率 85% 不点亮，L2 需 ≥98%）。

用途：单实体技术画像（某厂商点亮了什么、在哪条 beeline 上）、多路径对比、趋势推演、友商对标。

## 快速开始

依赖：Python 3.10+（仅构建/校验需要；交付 HTML 无任何依赖）。

**路径零配置**：两个 Python 脚本（`validate_tech_tree.py` / `build_viz.py`）均以**脚本自身所在目录**定位数据与产物——整个目录克隆、拷贝到任意路径（含跨设备交接）即可直接运行，无需修改任何路径配置。

```bash
# 1. 校验数据（196 节点/18 路径；生成 enriched 与报告）
python validate_tech_tree.py

# 2. 按需生成交付物（数据编辑不自动触发，需要分发时才执行）
python build_viz.py
#    → 智算科技树-v1.0.html（文件名固定，数据版本+构建时间显示在页面内）

# 3. 开发模式（改样式/逻辑/数据的实时迭代）
python build_viz.py --dev
#    → 浏览器访问 http://127.0.0.1:8932/viz/ ，保存后刷新即生效

# 4. 内置自检（任意页面 URL 加 ?selftest，42 项断言）
#    http://…/?selftest → 标题显示 [PASS]/[FAIL]
```

## 可视化特性

- 主干 = 横向子树带（tidy-tree）；粗彩色边 = 主干内主路径，细灰边 = 跨主干/次级依赖；
- **横轴 = 全局依赖深度，所有依赖边严格从左到右**（依赖外部主干的高阶入口自动右移，如 H 通智一体从深度 3 起步）；
- 三态强区分：已点亮（实色+✓）/ 可点亮（彩边呼吸光+●）/ 锁定（灰暗）；
- 点击点亮（前置校验、级联取消）、**双击弹出节点详情与点亮判据**、悬停高亮祖先链与解锁树、算力画像（K 主干）；
- 搜索联想下拉：输入即列出全部匹配节点（ID/名称/描述，最多 12 条），↑↓ 键盘导航、回车或点击定位，目标节点金色脉冲闪烁高亮；
- 胜利面板：18 条路径闭包进度条、演示点亮、V5 约束模式（国产化硬约束 +5 节点）。

## 数据模型

```jsonc
// 节点
{ "id": "D9", "name": "PD 分离", "trunk": "D", "frontier": false,
  "desc": "DistServe/Mooncake/火山", "profile": "…算力画像（可选）",
  "prereqs": ["D4", "B2"],              // 且：全部必要
  "prereqsAny": [["A8"], ["A14"]],      // 或：组内任一（虚线边）
  "criteria": "L2：goodput ≥2×" }       // 点亮判据（指标门槛型）

// 胜利路径：路径内 AND，路径间 OR
{ "id": "V1P1", "name": "系统压缩线", "nodes": ["D4","D7","D8","C17"],
  "currentTier": "银", "representatives": "DeepSeek、GPT-OSS、K3" }
```

- 修改节点/边：编辑 `智算科技树-graph-v0.3.json` → `python validate_tech_tree.py`（脚本头部 `EXPECT_NODES/EXPECT_PATHS` 同步改）→ `python build_viz.py` → `?selftest` 确认 [PASS]；
- 修改视觉：`viz/style.css` / `viz/config.js`；修改交互：`viz/app.js`——均不影响数据。
